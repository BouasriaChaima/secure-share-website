"SecureShare"

Your files shared and stored with complete confidentiality.

Built With

Python / Flask — backend & routing
HTML / CSS / JavaScript — frontend
Jinja2 — HTML templating
SQLAlchemy — database ORM
SQLite — database
Fernet (cryptography) — file encryption
SMTP (Gmail) — email verification & notifications

Features

-Email verification on sign up
-Automatic file encryption on upload
-Upload, download, and manage your files
-Mark files as favorites and filter by category
-Share files via a unique access code sent by email
-Collaborative folders with role-based permissions (Viewer / Editor / Owner)
